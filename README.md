issue1:
為甚麼火源點跟煙霧看起來沒有很相關?
從直覺上看，「有火的地方應該要有最多的煙」，但如果你在程式產出的灰階火場圖中發現 「火源點（Red Dots）的位置跟濃煙（黑色/深灰區域）看似沒有完全重疊或對齊」，這其實是由於數學模型設計與物理擴散機制所造成的，主要原因可分為以下 4 點：
1. 煙霧是「隨時間擴散」的（物理流體擴散模型）在論文的 公式 (3.12) 中，煙霧使用的是流體力學中的偏微分擴散模型：
   c_{new}(x,y) = c(x,y) + D t ( \frac{c(x+1,y)+c(x-1,y)+c(x,y+1)+c(x,y-1)}{4} - c(x,y) \right)
  $$火源點（Fire Points）：是固定產生煙霧的源頭（Source）。   
  煙霧（Smoke Matrix）：經過多個時間步長（$\Delta t \times \text{steps}$）
  之後，會從火源點向周圍的四個方向（上下左右）均勻擴散開來。   
  結果：經過多次擴散迭代後，煙霧會形成一個廣闊的煙霧雲（Smoke Cloud）。當周圍網格都被煙霧填滿時，火源點本身只會是這片大濃煙中的其中一個像素點，視覺上火源點就會被「包在濃煙裡面」，導致火源點與煙霧的外輪廓看起來不完全一致。   
2. 灰階影像的「標準化與反轉 (Min-Max Normalization)」在論文的 公式 (3.14) 與 (3.15) 中，為了將煙霧矩陣 $M$ 轉化為與建築物網格相容的 $[0, 255]$ 灰階值：
   $$M_{x,y} = 255 \left( \frac{M_{xy} - \min(M)}{\max(M) - \min(M)} \right), \quad New\_M = 256 - M$$矩陣數值經過全圖的最大值（$\max$）與最小值（$\min$）拉伸後，只要某個區域的煙霧濃度達到一定程度，反轉後的灰階值就會快速接近 0（純黑/極深灰）。   這會導致「高濃度煙霧區」和「最高火源點」在影像上全都變成一片黑，打破了線性視覺對比，讓人視覺上覺得火源與煙霧好像沒有顯著的邊界對應。
3. 多個火源點的「煙霧疊加效應 (Superposition)」在泊松分佈（Poisson Distribution）產生的多個火源點中：   當兩個火源點 $F_1$ 與 $F_2$ 距離較近時，各自擴散出去的煙霧會在中間區域相遇並疊加（Concentration Addition）。這會使得兩火源之間的區域煙霧濃度反而比單一火源點周圍更高、顏色更黑！因此視覺上會覺得「最黑/最危險的地方好像不在火源點正上方，而是在火源交會處」。
4. 地圖障礙物（牆壁）阻擋煙霧建築物地圖中有牆壁與不可通行區（灰階值 0）。當火源靠牆或在狹窄通道時，煙霧無法穿牆，只能順著走廊通道擴散。這會造成煙霧形狀變成長條狀或不對稱形狀，與點狀（Point Source）的火源形狀完全不同。   💡 總結與檢查建議邏輯上是完全正確的：火源是「點」，煙霧是「面（擴散場）」。火源點就像是煙囪，而煙霧是漂散出去的雲霧，兩者的幾何形狀本來就不會長得一樣。如何驗證程式沒寫錯？你可以嘗試將擴散步長降為 steps = 1 或 steps = 5（剛燃燒時）：在步長極短時，你應該會看到黑色濃煙精準地以火源點為中心呈現小圓形擴散。當 steps = 60 時，煙霧擴散開來形成大片危害區，這正符合真實火場「濃煙蔓延範圍遠大於火源本身」的物理現象！
